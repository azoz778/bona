# SEO keyword map — Bona (Jeddah luxury real estate), AR + EN

Volumes are directional (Google KSA, monthly, Arabic dominant ~85/15). Intent: **T** transactional, **C** commercial-investigation, **I** informational, **L** local/brand. Bona should not chase portal-scale head terms (عقار / aqar / bayut own them); the play is *luxury + district + type* long-tail, bilingual, with the AR page as the primary ranking page for Arabic queries.

## 7. Informational (AI-Overview / GEO targets — answer in ≤60-word blocks on the page)
- كيف أشتري فيلا في جدة؟ خطوات شراء عقار في السعودية (ناجز، الصك، الرسوم) → education post + /about/ FAQ
- هل يحق للأجانب تملك عقار في جدة؟ / can foreigners buy property in jeddah 2026 → FAQ (answer carefully; law expanded 2025 — say "case by case")
- ما الفرق بين الفيلا والدوبلكس؟ · ما هي رخصة فال؟ · what is FAL licence Saudi
- أفضل أحياء جدة للسكن الفاخر / best neighbourhoods in jeddah for expats → district guides
- Never target: "أسعار الفلل في جدة 2026", "توقعات أسعار العقار" (price forecasts = TAQEEM/REGA exposure).

## 8. Negative / avoid
شاليهات · استراحات · أراضي منح · شقق رخيصة · تمويل عقاري (not a lender) · تقييم عقاري (never — refer to TAQEEM valuers).

## 9. On-page rules for the site agent
1. `<h1>` = one primary keyword per page, never the brand alone (home: "Private luxury real estate in Jeddah" / "عقارات فاخرة خاصة في جدة").
2. Listing pages: `<h1>` = title; first paragraph includes type + district + city in both languages' pages; image `alt` = "{type} in {district}, Jeddah — {room}" (already in listings.json).
3. District names appear as visible text (not only in filters) — a "Districts we cover" block on the home and properties pages.
4. Internal links: every listing → its district filter; every district guide → 3 listings.
5. Arabic pages use real Arabic headings (no transliteration), `lang="ar"` `dir="rtl"` (already in Base).
6. Titles ≤ 60 chars, descriptions ≤ 155 chars — see `page-meta.json` for the exact copy per page.

## 10. Per-page title / description recommendations
See `marketing/page-meta.json` — `{ path: { title: {en, ar}, description: {en, ar} } }`. Listing pages use the template key `/properties/[slug]/`:
- title EN: `{title} — {district}, Jeddah | Bona` · AR: `{title} — {district}، جدة | بونا`
- description EN: `{type} in {district}, {city}: {beds} bedrooms, {baths} bathrooms, {area} m². {price}. Viewings by appointment — WhatsApp Bona.` · AR: `{type} في {district}، {city}: {beds} غرف نوم، {baths} دورات مياه، {area} م². {price}. المعاينة بموعد — واتساب بونا.`
