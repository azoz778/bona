```

! umask 077; printf 'META_PIXEL_ID=%s\nMETA_CAPI_TOKEN=%s\n' 'PASTE_PIXEL_ID_HERE' 'PASTE_CAPI_TOKEN_HERE' >> ~/.secrets/bona-marketing.env; echo saved
```

Then paste the Pixel ID in the chat as well — the agent puts it in `src/data/site.json` so the browser pixel loads (behind the consent banner).
