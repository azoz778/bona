# Codex second-opinion review — b1 (2026-09-06)

1. [services/api/index.mjs](/home/azoz778/bona-wt/concierge-api/services/api/index.mjs:337) MED: browser-facing paid endpoints rely on CORS only. A disallowed origin gets no readable response, but the request can still execute and burn Retell calls if sent as a simple cross-origin request or server-side request. Fix: reject requests with an `Origin` header not in the allowlist before body parsing/Retell calls, and require `Content-Type: application/json` for POST browser routes.

2. [services/api/lib/ratelimit.mjs](/home/azoz778/bona-wt/concierge-api/services/api/lib/ratelimit.mjs:46) MED: rate limiting blindly trusts `CF-Connecting-IP` / first `X-Forwarded-For`. Cloudflare documents `CF-Connecting-IP` for proxied origin traffic, but Tunnel docs also note Tunnel origin requests are internal through `cloudflared`; either way, these headers are only trustworthy if the API is reachable solely from trusted local/cloudflared paths. Fix: keep bind to `127.0.0.1`, validate `remoteAddress` is loopback before honoring forwarded headers, otherwise use socket IP.

3. [services/api/lib/store.mjs](/home/azoz778/bona-wt/concierge-api/services/api/lib/store.mjs:67) MED: `sessions` are capped, but `calls` and `byExternal` are not. Authenticated tool calls with many distinct `call_id`s can grow memory until TTL, and `sweep()` never enforces a call cap. Fix: cap calls and external mappings too, evict oldest entries, and expose/test stats for all maps.

4. [services/api/lib/tools.mjs](/home/azoz778/bona-wt/concierge-api/services/api/lib/tools.mjs:103) MED: `create_lead` is not idempotent. Prompt injection or Retell retries can append duplicate leads and send repeated WhatsApp notifications. Fix: add a per-conversation/contact dedupe key with short TTL, and return the existing lead id on duplicate tool calls.

5. [services/api/index.mjs](/home/azoz778/bona-wt/concierge-api/services/api/index.mjs:353) MED: all Retell failures collapse to `502`. `429` should preserve backpressure, and `402`/billing exhaustion should be distinguished operationally. Fix: map `RetellError.status === 429` to `429` with `Retry-After` if available; map `402` to `503 retell_payment_required` or similar, without exposing upstream body.

6. [services/api/lib/actions.mjs](/home/azoz778/bona-wt/concierge-api/services/api/lib/actions.mjs:19) LOW: `safePath()` allows any syntactically same-site path, including encoded traversal-looking paths and non-existent routes, while the prompt promises a fixed route set. Fix: enforce an explicit allowlist of known paths, plus `/ar` variants, after URL decoding and normalization.

7. [services/api/lib/tools.mjs](/home/azoz778/bona-wt/concierge-api/services/api/lib/tools.mjs:20) LOW: `tokenMatches()` is timing-safe only after equal length; length mismatch returns early. With a fixed 32-hex token this is not an auth bypass, but it leaks token length. Fix: compare fixed-length SHA-256/HMAC digests of provided and expected tokens and separately require both inputs non-empty.

8. [services/api/lib/inventory.mjs](/home/azoz778/bona-wt/concierge-api/services/api/lib/inventory.mjs:405) LOW: first-load inventory failure silently serves an empty portfolio and `/health` still reports `ok: true`. During non-atomic publisher writes, startup can cache empty inventory until next reload interval. Fix: fail startup or report degraded health when the initial inventory cannot parse; require publisher-side atomic rename.

9. [services/api/retell/prompt.md](/home/azoz778/bona-wt/concierge-api/services/api/retell/prompt.md:42) LOW: prompt has strong inventory/TAQEEM rules, but no explicit instruction that visitor text, page titles, and tool args are untrusted and must not override policy or fabricate lead fields. Fix: add an “untrusted input” rule, and pair it with server-side validation/dedupe because prompt text is not a control boundary.

10. [services/deploy/bona-api.service](/home/azoz778/bona-wt/concierge-api/services/deploy/bona-api.service:26) LOW: systemd hardening is partial. Fix: add `ProtectSystem=strict`, `ReadWritePaths=%h/bona-data`, `ReadOnlyPaths=%h/bona/services %h/.secrets`, `PrivateDevices=true`, `ProtectClock=true`, `ProtectKernelTunables=true`, `ProtectKernelModules=true`, `RestrictAddressFamilies=AF_INET AF_INET6 AF_UNIX`, and `LockPersonality=true`, testing against Node and outbound Retell/Evolution calls.

11. [services/deploy/install.sh](/home/azoz778/bona-wt/concierge-api/services/deploy/install.sh:145) LOW: predictable `/tmp/bona-*.json/log` paths are symlink/race-prone and shared across runs. Fix: use `mktemp -d`, trap cleanup, and write temp unit files inside that private directory before atomic move.

DO-NOT-SHIP.
