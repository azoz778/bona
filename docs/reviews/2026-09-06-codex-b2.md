# Codex second-opinion review — b2 (2026-09-06)

1. [src/components/concierge/api.ts](/home/azoz778/bona-wt/concierge-ui/src/components/concierge/api.ts:36) HIGH: `?concierge_api=` accepts any origin and stores it in `sessionStorage`, so a crafted production link can route all chat text/page path, call-token requests, call context, and potentially browser voice setup to an attacker-controlled API. Text rendering is mostly XSS-safe, but this is still user-data exfiltration and remote behavior control.  
Concrete fix: only honor the override on localhost/dev hosts, or require the override origin to be same-origin / explicit allowlist. Also clear a stored override when it is not allowed.

2. [src/components/concierge/client.ts](/home/azoz778/bona-wt/concierge-ui/src/components/concierge/client.ts:178) HIGH: closing the panel does not stop an active or connecting Retell call; [unbind](/home/azoz778/bona-wt/concierge-ui/src/components/concierge/client.ts:119) on `astro:before-swap` also leaves the `CallSession` alive. That means microphone/audio can continue after the user closes the UI or navigates.  
Concrete fix: call `this.call.end()` or `this.call.dispose()` when closing and in `unbind()`, unless there is an explicit persistent-call UX with a visible live indicator and stop control across pages.

3. [src/components/concierge/call.ts](/home/azoz778/bona-wt/concierge-ui/src/components/concierge/call.ts:70) MED: call startup is not cancellable. If the user closes the widget or navigates while the microphone probe, token request, SDK import, or `startCall()` is pending, the async path can still create/start a Retell client after the UI is gone.  
Concrete fix: add an `AbortController` or monotonically increasing `startId`, check it after every await, and have `dispose()` invalidate pending starts before stopping the client.

4. [src/components/concierge/render.ts](/home/azoz778/bona-wt/concierge-ui/src/components/concierge/render.ts:67) MED: API-provided card image URLs are assigned directly to `img.src`. That is not normal script XSS, but it allows arbitrary third-party tracking pixels/media from API responses and accepts non-HTTPS/data/blob schemes.  
Concrete fix: add a `safeImageSrc()` helper that only permits same-origin paths and approved HTTPS image/CDN origins; otherwise omit the image.

5. [src/components/concierge/client.ts](/home/azoz778/bona-wt/concierge-ui/src/components/concierge/client.ts:319) MED: full chat contents, including user-entered phone numbers/budget/preferences and API-returned messages/cards, are persisted indefinitely for the tab in `sessionStorage`. The privacy text does not disclose local browser persistence, and a later same-origin XSS anywhere on the site could read it.  
Concrete fix: store only `sessionId` and minimal UI state, or add a short TTL plus clear-on-close/new-conversation. Mention local `sessionStorage` in the privacy policy if retained.

6. [src/components/concierge/client.ts](/home/azoz778/bona-wt/concierge-ui/src/components/concierge/client.ts:438) LOW: updating the call timer with `timer.textContent = this.elapsed()` removes the existing screen-reader label rendered in [Concierge.astro](/home/azoz778/bona-wt/concierge-ui/src/components/concierge/Concierge.astro:138). After the first tick, assistive tech only sees `0:12`, not “Call duration: 0:12”.  
Concrete fix: render the changing time in a child span, e.g. `<span data-cg-timer-value>0:00</span>`, and update only that node.

7. [src/data/privacy.json](/home/azoz778/bona-wt/concierge-ui/src/data/privacy.json:73) MED: the AI concierge privacy addition is too narrow/inexact for the actual implementation. The browser sends text/page/language to `bona-api.azoz.uk`, uses Retell for voice, may involve another AI model provider, and stores conversation state locally in `sessionStorage`; the policy only names Retell/model processing and recording/transcription.  
Concrete fix: disclose the Bona API/backend, Retell voice processing, any model provider used by the backend, local browser storage, retention period, and how users can clear/request deletion of concierge conversations.

No direct `innerHTML` XSS finding: agent text, captions, WhatsApp message text, and card text are inserted with `textContent`; navigate/card links are same-origin constrained. `retell-client-js-sdk` is exactly pinned at `2.0.8`.

DO-NOT-SHIP until the arbitrary `concierge_api` override and call lifecycle issues are fixed.
